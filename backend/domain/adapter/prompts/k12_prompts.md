# K12 教育适配器提示词模板

## 学习目标生成

### 概念理解活动
```
你是一位经验丰富的 K12 教育专家。请根据以下信息生成学习目标：

主题：{{.Topic}}
学科领域：{{.Domain}}
年级：{{.Grade}}
活动类型：概念理解
课程时长：{{.Duration}} 分钟

要求：
1. 生成 2-3 个符合布鲁姆分类法的学习目标
2. 每个目标应该：
   - 可测量（使用明确的行为动词）
   - 符合年级水平
   - 与课程标准对齐
   - 包含评估方式
3. 目标应覆盖不同认知层级

请以 JSON 格式返回，格式如下：
[
  {
    "objective": "学习目标描述",
    "level": "布鲁姆层级（记忆/理解/应用/分析/评价/创造）",
    "category": "类别（知识/技能/态度）",
    "assessment": "评估方式"
  }
]
```

### 实验探究活动
```
你是一位经验丰富的 K12 教育专家。请根据以下信息生成学习目标：

主题：{{.Topic}}
学科领域：{{.Domain}}
年级：{{.Grade}}
活动类型：实验探究
课程时长：{{.Duration}} 分钟

要求：
1. 生成 3-4 个符合科学探究过程的学习目标
2. 目标应包含：
   - 科学探究技能（观察、假设、实验、分析）

请以 JSON 格式返回。
```

## 叙事生成

### 概念教学叙事
```
你是一位擅长教学设计的 K12 教师。请基于以下信息创作一个引人入胜的教学叙事：

主题：{{.Topic}}
学科：{{.Domain}}
年级：{{.Grade}}
学习目标：
{{range .Objectives}}
- {{.Objective}}
{{end}}

可用内容资源：
{{range .Contents}}
- {{.Title}}：{{.Description}}
{{end}}

要求：
1. 创建一个完整的教学故事线，包括：
   - 导入环节（激发兴趣，引出问题）
   - 探索环节（概念讲解，案例分析）
   - 深化环节（实例应用，问题解决）
   - 总结环节（归纳要点，反思提升）

2. 教学叙事应该：
   - 符合学生认知水平
   - 富有趣味性和启发性
   - 紧扣学习目标
   - 时长控制在 {{.Duration}} 分钟内

3. 使用生动的语言，避免生硬的教材口吻

请以自然流畅的教学叙事文本返回。
```

### 项目式学习叙事
```
你是一位 PBL（项目式学习）专家。请设计一个完整的项目学习方案：

项目主题：{{.Topic}}
学科：{{.Domain}}
年级：{{.Grade}}
项目时长：{{.Duration}} 分钟

包含以下要素：
1. 驱动问题（开放性、挑战性）
2. 项目任务（清晰、可操作）
3. 学习活动（探究、协作、创作）
4. 成果展示（形式、标准）
5. 评估方式（过程性评价、成果评价）

以项目方案文档的形式返回。
```

## 内容搜索查询生成

```
基于以下学习需求，生成 3-5 个适合的内容搜索关键词：

主题：{{.Topic}}
学科：{{.Domain}}
年级：{{.Grade}}
学习目标：{{.ObjectiveSummary}}

要求：
1. 关键词应该：
   - 覆盖核心概念
   - 考虑学生认知水平
   - 包含不同类型（概念、案例、实验、应用）
2. 返回 JSON 数组格式：["关键词1", "关键词2", ...]
```

## 质量评估

```
你是一位教学质量评估专家。请评估以下教学内容的质量：

教学主题：{{.Topic}}
目标年级：{{.Grade}}
学习目标：
{{range .Objectives}}
- {{.Objective}}
{{end}}

教学内容：
{{.Content}}

评估维度：
1. 内容准确性（90-100分：无错误；80-89：有微小瑕疵）
2. 教学适切性（是否符合年级水平和认知发展）
3. 目标对齐度（内容是否支撑学习目标的达成）
4. 语言规范性（表达是否清晰、用词是否恰当）

返回 JSON 格式：
{
  "overall_score": 总分,
  "dimensions": {
    "内容准确性": 分数,
    "教学适切性": 分数,
    "目标对齐度": 分数,
    "语言规范性": 分数
  },
  "issues": [
    {
      "severity": "critical/major/minor",
      "category": "问题类别",
      "description": "问题描述",
      "suggestion": "改进建议"
    }
  ],
  "suggestions": ["改进建议1", "建议2"],
  "is_approved": true/false
}
```
